# 附錄 C：XCC 命令列參數與安全保護配置指南

本附錄提供 XCC 編譯器驅動程式（[`src/main.c`](file:///Users/hcwtony/repo/projects/ccompiler/src/main.c)）的完整命令列旗標說明與安全保護等級配置最佳實踐。

---

## C.1 基本編譯與診斷選項

| 命令列參數 | 參數類型 | 功能說明 |
| :--- | :--- | :--- |
| `-o <file>` | 檔案路徑 | 指定輸出檔案名稱（預設為 `a.out` 或替換副檔名）。 |
| `-target <name>` | 目標平台 | 指定交叉編譯目標平台：<br>• `arm64-macos`<br>• `arm64-linux`<br>• `x86_64-macos`<br>• `x86_64-linux`<br>• `x86_64-windows` |
| `-E` | 旗標 | 僅執行前置處理器，展開巨集與標頭檔後輸出到 stdout。 |
| `-S` | 旗標 | 僅執行編譯，發射目標架構的組合語言文字檔（`.s`）。 |
| `-c` | 旗標 | 編譯並呼叫組譯器，產生目標機器碼檔案（`.o`）。 |
| `--run` | 旗標 | 編譯為原生執行檔並立即載入執行，回傳程式退出代碼。 |
| `--run-ir` | 旗標 | **直接使用內建 IR 虛擬機在記憶體中執行**，不透過外部組譯器。 |
| `--emit-ast` | 旗標 | 傾印語法分析後的抽象語法樹（AST）結構。 |
| `--emit-ir` | 旗標 | 傾印平台無關三址碼 IR（若啟用混淆則顯示強化後的 Custom IR）。 |
| `-I <dir>` | 目錄路徑 | 新增 `#include` 標頭檔搜尋目錄。 |
| `-D <name>[=<val>]` | 巨集定義 | 在前置處理器中預先定義全域巨集常數。 |
| `-h`, `--help` | 旗標 | 顯示說明訊息並退出。 |

## C.2 抗逆向工程與安全保護選項

| 混淆參數 | 簡寫 | 功能說明與安全機制 |
| :--- | :---: | :--- |
| **`--obf`** | `-fobf` | **基礎全套混淆**：同時啟用 CFF、BCF、MBA 與字串加密。 |
| **`--obf-cff`** | — | **控制流平坦化**：建立中央狀態分派器，結合無分支位元狀態轉移。 |
| **`--obf-bcf`** | — | **虛假控制流**：注入數論不透明謂詞與幽靈基本塊。 |
| **`--obf-mba`** | — | **混合布林算術**：以帶多態金鑰的位元與算術恆等式重寫加減異或，並啟用動態常數加密（`IR_OBF_IMM`）。 |
| **`--obf-str`** | — | **編譯期字串流密碼加密**：消滅二進位檔中的 ASCII 字串與靜態 Xrefs。 |
| **`--obf-vm`** | `-fvm` | **多態 Bytecode 虛擬化**：將函式編譯為私有隨機 Bytecode 並嵌入自校驗直譯器。 |
| **`--obf-all`** | — | **雙軌最高強度防護**：將函式虛擬化為 Bytecode VM 後，再對虛擬機直譯器進行 CFF+BCF+MBA+字串加密。 |
| **`--obf-seed <uint64>`** | — | 指定 64 位元多態隨機種子（如 `0x1337BEEF`），生成唯一特徵碼。 |

## C.3 安全防禦等級配置建議（Security Profiles）

### 等級 1：日常發布標準防護（建議中小型工具使用）
消滅敏感字串與常數特徵，對執行效能幾乎零影響：
```bash
./xcc --obf-str --obf-mba my_tool.c -o my_tool
```

### 等級 2：商業軟體控制流防護（建議商業軟體常規版本使用）
消除字串並將所有業務分支打碎為無分支平坦化狀態機：
```bash
./xcc --obf-str --obf-mba --obf-cff my_app.c -o my_app
```

### 等級 3：金融／DRM 核心驗證旗艦防護（建議最高機密模組使用）
開啟雙軌虛擬化與自校驗防竄改，令靜態反組譯器與動態除錯器全面失效：
```bash
./xcc --obf-all --obf-seed 0x20261020 secure_core.c -o secure_core
```
